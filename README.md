# 🏥 MediCare+ — Hospital Appointment Website

A modern and user-friendly **Hospital Appointment Website** that allows patients to explore doctors, view healthcare services, and book appointments online.

The project is built using **HTML, CSS, and JavaScript** with a clean, responsive, and GenZ-inspired healthcare design.

---

## ✨ Features

* 🏥 Modern hospital landing page
* 👨‍⚕️ View available doctors and their specializations
* 🩺 Explore hospital services
* 📅 Book doctor appointments
* 👤 Select a specific doctor directly from the doctor card
* 📝 Appointment form with validation
* ✅ Appointment confirmation message
* 📱 Responsive design for mobile, tablet, and desktop
* 🍔 Responsive hamburger navigation menu
* 📩 Contact form
* 🚫 Prevent selection of past appointment dates
* 🔄 Dynamic appointment details
* ✨ Smooth scrolling and hover effects
* 🎨 Clean healthcare + GenZ-inspired UI
